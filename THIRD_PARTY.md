# Third-party provenance

The headless v12 tuner is an independent ESP32/TWAI adaptation of protocol behavior documented in:

- **Twizy-Cfg**, Michael Balzer / dexterbg, LGPL: `TwizyCfg/CANopen.ino` at commit `684150ac9d375cd41a23ff08bf4e87024776e67f`
- **Open Vehicle Monitoring System 3**, Renault Twizy SEVCON components, MIT-licensed source at commit `1aa1daff19c5ad8532ba9fc887187c7f301539ac`

No source file is copied verbatim. The project retains these notices and references because the register/login/state behavior was validated against those implementations.
